# 能力评价低保真产品原型

用于结构、规则与交互评审，使用停送电操作实验的示例步骤数据。原型未接入真实教学后台或 AI 服务。

## 页面

| 入口 | 内容 |
| --- | --- |
| `index.html?view=admin` | 3–8 个维度；步骤多选；每维度 2–5 级；固定 Lv1–Lv5；阈值与试算 |
| `index.html?view=import&sample=1` | 两张 Excel 表的上传、校验、单元格编辑和导入草稿 |
| `index.html?view=admin&review=1` | 全维度试算及新版本发布确认 |
| `index.html?view=student` | 雷达图、等级区间、步骤得分依据；缺失/零分状态 |
| `index.html?view=logic` | 数据流、版本绑定、计算与异常规则 |
| `overview.svg` | 四屏低保真页面总览 |

## 规则与边界

- 维度分 = 关联步骤得分合计 ÷ 满分合计 × 100；同一步骤可关联多个维度。
- 判级使用未四舍五入的分数；显示一位小数。Lv1 起点为 0，其余阈值严格递增且小于 100，最后一级包含 100。
- 未回传得分显示待评价；明确的 0 分参与计算。操作次数与用时不重复扣分。
- Excel 包含“能力维度表”“步骤表”。同一维度按行产生等级，导入先复核，再替换草稿；发布为独立操作。
- 样例步骤目录用于导入匹配，满分须与目录一致；当前演示中不支持新增未知步骤。
- 保存、发布仅模拟当前页面会话状态；刷新后恢复示例。正式产品需要服务端保存版本和历史快照。
- `app.js` 与 `app.css` 为可读源文件；`index.html` 将相同内容封装在沙箱 iframe 中，允许模板文件下载。
- 项目根目录 `index.html` 保留用户原始导出文件，不随本次原型新增而改写。

## 编辑与验证

修改 `app.js` 或 `app.css` 后，在仓库根目录运行 `node prototype/build.mjs` 更新沙箱入口。无需安装 npm 依赖；Excel 上传解析使用 CDN 上的 SheetJS，离线时可使用示例演示。

浏览器已验证：完整样例试算为 80 / 100 / 84.4 / 80 / 80；步骤 06 缺失时相关维度待评价，实得 0 分时操作执行为 51.1 / Lv1；导入表分界值未递增时标注问题行并禁止确认导入。
